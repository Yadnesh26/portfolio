# Yadnesh's Portfolio

A modern, high-performance portfolio website built with React, Vite, and Tailwind CSS. It showcases projects, skills, and contact information using smooth animations and dynamic layouts.

## Features
- **Responsive Design**: Fully optimized for desktop and mobile layouts.
- **Smooth Animations**: Powered by Framer Motion for elegant scroll and hover interactions.
- **Contact Form**: Functional, serverless contact form paired with EmailJS.
- **Project Showcase**: Custom display case for GitHub repositories and live hosted projects.

## Tech Stack
- React
- Vite
- Tailwind CSS
- TypeScript
- Framer Motion

## Getting Started Locally

1. Clone the repository:
   ```bash
   git clone <your-repo-link>
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server on localhost:
   ```bash
   npm run dev
   ```
